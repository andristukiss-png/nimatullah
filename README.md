# Nimatullah

**نعمة الله · NIMATULLAH**

**MAKE GOOD VISIBLE**

Early website prototype for Nimatullah: a global platform for the Muslim world to turn blessings into service, participation and measurable good.

## Current scope

- Next.js App Router
- English and Arabic routes
- RTL/LTR presentation
- Good Map prototype with illustrative-only data
- Prototype missions
- Principles and verification model
- Institutional enquiry pathway

This prototype intentionally contains no payment handling, accounts, fabricated impact statistics, partner claims, endorsements or verification claims.
